
# Sales Forecasting System

## Project Overview

This project analyzes historical monthly sales data and predicts future sales using Linear Regression.

The project was developed as part of the Cognevance Technologies Data Science & Data Analytics project tasks.

## Objectives

- Analyze historical sales data
- Calculate average, highest, and lowest sales
- Identify monthly sales trends
- Forecast future sales
- Visualize historical and predicted sales
- Generate business insights

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Linear Regression
